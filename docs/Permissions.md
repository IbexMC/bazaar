## Permissions

    bazaar.admin - Admin permission, gives access to all other permissions
    bazaar.create - Allows you to create player shops
    bazaar.create.admin - Allows you to create Admin shops
    bazaar.create.clan - Allows you to create clan shops
    bazaar.create.server - Allows you to create Server shops
    bazaar.remove - Allows you to remove your own player shops or clan shops for your clan
    bazaar.remove.admin - Allows you to remove admin shops
    bazaar.remove.server - Allows you to remove server shops
    bazaar.buy - Allows you to buy from shops
    bazaar.sell - Allows you to sell to shops
    bazaar.limit.<amount> - Sets a maximum number of shops for the player
